# Haema-Proto

대덕소프트웨어마이스터고 재학생을 위한 해커톤·공모전·대회 팀원 모집 서비스 프로토타입입니다.

## 서비스 개요

대마고 재학생이 대회에 함께 참여할 팀원을 모집하거나, 다른 팀의 모집 공고에 지원할 수 있는 서비스입니다. 모집 공고 게시부터 지원, 모집 결과 확인까지 하나의 서비스에서 제공합니다.

## 대상 사용자

대덕소프트웨어마이스터고 1·2·3학년 재학생. 상황에 따라 **모집자** 또는 **지원자** 역할을 수행합니다.

## 주요 기능

- **회원 관리**: 회원가입(학교 도메인 확인), 로그인, 마이페이지(이력 수정, 회원 탈퇴)
- **모집 공고**: 작성/조회/수정/삭제(CRUD). 댓글 기능 없음.
  - 필수 항목: 대회명, 원문 대회 URL, 모집 내용, 모집 인원, 연락 수단(이메일)
  - 목록은 최신 등록순 정렬
- **지원서**: 작성(내용만), 조회, 삭제. 상태: `지원함` → 모집자 수락 시 `수락됨`
- **지원자 관리**: 모집자의 마이페이지 → 내가 작성한 공고 → 지원자 목록 → 수락/거절
- **내 지원 현황**: 마이페이지 → 내가 지원한 공고 → 결과 확인

## 회원 역할

- 회원은 기본적으로 익명입니다(게시글 작성 시 정보 노출은 감수).
- 인증: JWT 사용.
- 도메인: 유저 도메인(회원가입/로그인/마이페이지), 게시글 도메인(공고 CRUD), 신청서 도메인(공고 지원 C/R/D).
