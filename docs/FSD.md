# 기능 목록

## 공통

- 로그인
- 회원가입
- 마이페이지
- 이력 수정
- 공고 상세 확인

## 모집자

- (모집자가) 올린 공고
- 공고 작성
- 공고 조회
- 공고 수정
- 공고 삭제
- 지원자 확인
- 지원 수락

## 지원자

- (지원자가) 지원한 공고
- 지원서 작성
- 공고 지원
- 지원 상태 표시(신청됨/수락됨)

# 기능 유의점

## 회원가입

- 이메일, 비번, 비번 인증을 입력
- 회원은 남에게 전부 익명으로 보여짐. (만약 게시글 올릴 때 정보 노출은 감수)

## 마이페이지

- 회원 정보 수정 X, 이력 내역 수정 가능

## 공고 관련

- 공고는 대회명, 원문 대회 URL, 모집 내용, 인원, 연락 수단(이메일)을 포함
- 공고는 CRUD가 가능해야 하며, 댓글 기능은 없음

## 지원자 확인

- 지원자 확인은 모집자의 마이페이지 → 내가 작성한 공고에서 보여

## 지원 상태 표시

- 지원한 상태는 `지원함`, 모집자가 수락하면 `수락됨` 상태로 전환됨.

# 기타 백엔드 참고 사항
- JWT 사용

- 로그인
    - 유저 도메인
- 회원가입
    - 유저 도메인
- 마이페이지
    - 유저 도메인
- 내가 올린 공고
    - (내가 올린 공고 상세)게시글 R / U / D
- 공고 조회
    - 게시글  R
- 공고 상세
    - 게시글 R / U / D
- 공고 작성 페이지
    - 게시글 C
- 내가 지원한 공고
    - 게시글 R
    - 신청서 R / D
- 공고 지원
    - 신청서 C (내용만. 들어갈 내용은 공고 모집하는 사람이 본문에 적어두기)
